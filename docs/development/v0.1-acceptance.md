# v0.1 acceptance criteria

v0.1 is accepted when every item below is true in this repository and covered by a test or by a documented operational check.

| Criterion | Evidence |
| --- | --- |
| Repository contains the control plane, packages, schemas, tests, Compose, CI, and safety docs | Layout in the README |
| API serves `GET /health` without a token | `tests/integration/test_api.py` |
| `GET /ready` reports database connectivity | Integration test and Compose health check |
| Alembic applies the initial schema, including the audit trigger | Integration session runs `upgrade head` twice; migration `0001_initial` |
| A target stores id, owner, scope, status, expiry, capabilities, and timestamps | `POST /api/v1/targets` |
| Past expiry, revoked status, bad scope, and unknown capabilities fail closed | Unit policy tests and API tests |
| An ineligible target cannot open or advance a case | API test for expiry and revocation |
| Case states follow only the linear pipeline | Unit transition tests and API walk through `SEALED_AUDIT` |
| Illegal transitions leave the case unchanged | API test that skips to `ACTION` |
| No transition executes a program | `executed` is false; source scan rejects a shell API |
| Audit events include id, time, actor, type, target, case, payload, previous hash, and hash | API audit test |
| The hash chain verifies, and a tampered payload fails verification | Unit chain tests and `GET /api/v1/audit/verify` |
| Application-level update and delete of audit events fail | Owner trigger test and `synapse_app` privilege test |
| Missing and unknown tokens return 401; a viewer write returns 403 | API auth tests |
| Secrets are read from the environment | `synapse_api.config`; `.env` is gitignored |
| Claims document states the non-goals | `docs/safety/claims.md` |

Out of acceptance for v0.1: telemetry, evidence reproduction, reasoning, Z3, mitigation, rollback execution, and an end-to-end defense scenario.
